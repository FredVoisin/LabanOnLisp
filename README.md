# LabanOnLisp

Lisp Environment For Choreography, by Myriam Gourfink, Kasper T. Tœplitz & Fred Voisin

LabanOnLisp (LOL) est un environnement de composition chorégraphique
assistée par ordinateur, écrit en Common Lisp, qui décrit le corps
dansant à l'aide de dimensions inspirées de la notation Laban.

## Versions historiques

Le dossier [`legacy/`](legacy/) conserve les sources d'origine
(Macintosh Common Lisp, 1999-2001), dont la version utilisée pour
*L'Écarlate* (Ircam, 2001). Voir aussi le projet associé
[neuromuse](https://github.com/FredVoisin/neuromuse).
