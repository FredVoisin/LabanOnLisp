# Versions historiques de LabanOnLisp

Ce dossier conserve des états anciens de LabanOnLisp (LOL), à titre de
référence. Ils sont archivés tels quels et ne sont pas maintenus : ils
ne sont pas destinés à être corrigés ni chargés avec une version
actuelle.

Les fichiers de ce dossier ne sont pas couverts par la licence MIT du
dépôt : voir [LICENSE](LICENSE).

| Version | Date | Environnement | Description |
|---|---|---|---|
| [LOL-2001-concert](LOL-2001-concert/) | 1999-2001 | MCL 4.x, Mac OS 9 | LOL 3.0, environnement de composition chorégraphique assistée par ordinateur, avec la partition de *L'Écarlate* (Ircam, 7 juin 2001), en lien avec [neuromuse](https://github.com/FredVoisin/neuromuse) |

D'autres versions antérieures (LOL 2.x, 1999-2000) pourront être
ajoutées ultérieurement.
